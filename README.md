# 우리들의 여름

창작 한국 고교와 자동 생성 선수를 운영하는 웹 야구 감독·육성 게임 개발판입니다. 2D 감독실·전술판과 빠른 점수 시뮬레이션을 사용합니다.

- [새 게임 플레이](https://toddchoi.github.io/our-summer-baseball-preview/)
- [졸업·입학·다음 학년도 체험](https://toddchoi.github.io/our-summer-baseball-preview/demo.html?slot=1#home)

새 게임에서 학교와 감독을 선택하고 훈련 카드 3장을 확정하면 날짜별로 진행합니다. 경기에서는 전체 자동 경기를 선택하거나 감독 지휘로 결정에 개입할 수 있습니다.

개선판에는 다음 투구의 2루 도루와 수비의 주자 견제 지시, 실제 도루·도루사 이력, 선수 고정 초상, 스카우트 명단표·카드 전환과 관찰 정보 기반 검색·필터·정렬을 추가했습니다. 후보 목록의 숫자는 표시 인원 / 전체 발견 인원입니다.

시즌 전환 체험은 실제 게임 엔진으로 완료한 시즌에서 시작합니다. 스카우트 후보를 살펴본 뒤 겨울 준비 네 구간, 입학 확정, 다음 학년도 전환을 진행할 수 있습니다. 본편과 다른 저장소를 사용합니다.

저장은 기기·브라우저별로 유지됩니다. 회사 PC의 로컬 게임 저장이 자동으로 이어지지는 않습니다. 기존 경력은 내보내기·가져오기를 사용하세요.

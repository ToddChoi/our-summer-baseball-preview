# 우리들의 여름

창작 한국 고교와 자동 생성 선수를 운영하는 웹 야구 감독·육성 게임 개발판입니다. 2D 감독실·전술판과 빠른 점수 시뮬레이션을 사용합니다.

- [새 게임 플레이](https://toddchoi.github.io/our-summer-baseball-preview/)
- [졸업·입학·다음 학년도 체험](https://toddchoi.github.io/our-summer-baseball-preview/demo.html?slot=1#home)

새 게임에서 학교와 감독을 선택하고 훈련 카드 3장을 확정하면 날짜별로 진행합니다. 경기에서는 전체 자동 경기를 선택하거나 감독 지휘로 결정에 개입할 수 있습니다.

개선판에는 다음 투구의 2루 도루와 수비의 주자 견제 지시, 실제 도루·도루사 이력, 선수 고정 초상, 스카우트 명단표·카드 전환과 관찰 정보 기반 검색·필터·정렬을 추가했습니다. 후보 목록의 숫자는 표시 인원 / 전체 발견 인원입니다.

훈련 화면에서 일상 면담을 코치에게 맡길 수도 있습니다. 기본은 직접 면담이며 피로·건강·신뢰·약속·성장 관련 중요한 요청과 예약 면담은 계속 감독에게 옵니다.

우리 학교 공식 경기의 도루·도루사를 학년도별로 볼 수 있습니다. 경력 전환 시 후보 검색 조건을 초기화하며, 출전 가능한 정규 투수가 없으면 건강한 벤치 야수가 임시 등판하고 경기 화면에 표시됩니다. 부상과 선발 계획은 그대로 유지됩니다.

첫 두 주에는 현재 진행 단계와 먼저 확인할 선수를 안내합니다. 훈련 카드의 순서를 바꾸고 회복 카드를 넣어 경기 전 기준 체력을 비교할 수 있습니다. 전망은 공개 정보로 계산한 훈련 계획의 비교이며 실제 체력·경기·능력 성장을 보장하지 않습니다.

빠른 경기 중계에는 2D 주자 상황도, 실제 베이스 이동 경로, 투수·타자와 구종·구속, 득점·동점·역전·끝내기 알림을 제공합니다. 일시정지·재개·1×·3×·건너뛰기는 이미 저장된 경기 구간을 표시하는 속도만 바꿉니다. 결과 화면의 주요 장면은 이번 중계 구간이며, 재접속 후에는 저장된 최근 투구 기록의 범위만 표시합니다.

스카우트 준비판에서 졸업 공백을 선택해 해당 주포지션 후보로 좁혀 볼 수 있습니다. 최대 세 후보의 관찰 범위·관찰된 구종·잔류 선수 기준·경쟁교 제안을 함께 비교하고 제안·철회 후 같은 화면을 유지합니다. 제안은 합류 확정이 아니며 투수 정원과 중복 관찰 예약·관찰 가능한 일정 및 권역을 표시합니다.

홈의 육성 명단에서 개인 목표와 출전 약속을 세운 선수를 이어서 관리합니다. 육성 과정에는 실제 개인 성장분, 목표 변경, 면담 신뢰 변화, 경기 기회와 약속 경과가 남습니다. 개인 성장분은 전체 성장에 이미 포함됩니다. 이력은 최근 최대 8개 활동 주·200건에 한정되며, 이전 저장에 없던 개인 내역은 미기록으로 표시합니다.

선발 계획에서 현재 선발과 대체 후보 두 명의 능력·체력·구종·최근 등판 부담·출전 약속을 비교할 수 있습니다. 벤치 교체 또는 두 선발의 수비 자리 교환과 기본 배치 수비 변화를 선택 전에 확인하고 편성합니다. 비교는 읽기 전용이며 편성은 명시적 선택 시 저장합니다. 기본 배치 수비는 성향·경기 상황을 제외한 능력 기준이며 승률 예측이 아닙니다.

시즌 전환 체험은 실제 게임 엔진으로 완료한 시즌에서 시작합니다. 스카우트 후보를 살펴본 뒤 겨울 준비 네 구간, 입학 확정, 다음 학년도 전환을 진행할 수 있습니다. 본편과 다른 저장소를 사용합니다.

저장은 기기·브라우저별로 유지됩니다. 회사 PC의 로컬 게임 저장이 자동으로 이어지지는 않습니다. 기존 경력은 내보내기·가져오기를 사용하세요.

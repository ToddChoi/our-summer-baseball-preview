# 우리들의 여름 — 독립 Godot 운영 실험

플레이 주소: https://toddchoi.github.io/our-summer-baseball-preview/godot-test/

20명 선수의 훈련 계획 → 타순 9칸·수비 9명·투수·DH 확인 → 간단한 9이닝 경기와 교체 → 성장·피로 결산 → 다음 날을 연속해서 플레이합니다. 선수 선택 후 훈련 종목·시간·기술 훈련 강도·추가 지도를 조정합니다. 미지정 선수도 자율 훈련하며, 팀 지도 자원은 하루 100으로 공유합니다. 경기일의 선수별 훈련 시간은 60분, 훈련만 하는 날은 240분입니다. 메뉴에서 이전 3명 기술 샘플도 실행할 수 있습니다.

경기는 한 타석씩 또는 자동으로 진행합니다. 투수/수비 이름표와 교체 버튼을 눌러 교체하며, 대타는 현재 타자, 대주자는 실제 출루한 주자에게만 적용됩니다. 수비 자리가 비면 해당 수비 배치를 먼저 정합니다. 재출전은 금지이고 투수는 최소 한 타자를 상대하거나 공수 전환이 끝나야 교체할 수 있습니다. DH 및 투수 겸 DH는 실험 규칙이며 실제 일본 고교 규칙으로 주장하지 않습니다.

체력용량 C는 같은 부하의 피로 발생을, 회복력 R은 실제 경과 시간의 피로 감소를 바꿉니다. R 훈련은 기술 훈련 시간과 지도를 소비합니다. 회복 후의 새 C/R은 다음 활동부터 적용됩니다. 일반 기술 성장과 실제 타석·수비·투구 경험은 분리했습니다. 벤치 등록·달력 진행·반복 저장만으로 경험이 늘지 않습니다. 부상·의무 휴식 및 별도 Q/누적 부하 변수는 구현하지 않았습니다.

자동 저장은 `management-save-v2.json`이며 이전 샘플의 `lab-save-v1.json`을 유지합니다. 스키마 1 불러오기 함수는 옛 데이터를 원형 보존하고, 20명·네 능력치로 허위 변환하지 않습니다. 손상된 저장은 자동으로 덮어쓰지 않습니다. 네이티브 저장·재실행은 테스트 전용 슬롯으로 검사했습니다. 브라우저 새로고침·영구 저장과 모바일 실기기는 Orca 연결 오류 때문에 미확인입니다.

Godot 4.7.2 Standard / GDScript / Compatibility / 단일 스레드 Web export입니다. 설치된 콘솔 실행 파일을 지정해 `./run-management.ps1 -Mode Verify -GodotPath <실행파일>`로 검사하고, `-Mode Compare`로 정책 비교를 재실행합니다. `./run-lab.ps1 -Mode Export -GodotPath <실행파일>`은 일치하는 Web export templates를 필요로 합니다. 엔진 실행 파일과 templates는 소스에 포함하지 않습니다. `Capture`는 포커스를 받지 않는 창에서 실제 렌더링과 엔진 내부 클릭을 검사합니다. 데스크톱 마우스 입력과 브라우저 검증은 별개입니다.

560개 정책 실행(조건당 8개 짝지은 시드), 7·30·90일 체크포인트, 반복 기계 검사 126,968회에서 실패가 없었습니다. 정책 비교는 고정 타석/수비/투구 노출의 대리 모델이며 새 9이닝 경기의 밸런스를 검증하지 않습니다. 원시 CSV 및 표준편차·범위·짝지은 차이는 `management-lab/benchmarks/`에 있습니다. 큰 일별/선수별 CSV는 gzip으로 보존했습니다. 자세한 근거와 한계는 `management-lab/RESULTS.md`에 있습니다.

본개발의 첫 운영 루프 실험입니다. 병살·도루·희생타·연장전·DH 소멸 전이·불펜 준비·구종 전술·부상·대회 진행은 남아 있습니다. 선수 3명만 승인된 개별 초상이고 나머지 17명은 고정 이름/번호와 공용 독자 도형으로 표시합니다. 타격/투구 프레임 애니메이션·음향·모바일 화면 최적화도 남아 있습니다. 기존 JS 게임 파일은 변경하지 않았습니다. 자산과 폰트 라이선스는 `CREDITS.html`에 있습니다.

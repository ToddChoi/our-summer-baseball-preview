# 우리들의 여름 — Godot 선수단 운영 실험 r7

[웹에서 플레이](https://toddchoi.github.io/our-summer-baseball-preview/godot-test/)

20명 선수의 훈련 계획, 라인업과 교체, 경기, 성장·피로 결산, 다음 날 운영을 이어가는 개발판입니다. 선수 명단에서 타자·투수 능력을 비교하고 선수를 선택해 상세 정보와 훈련 계획을 확인합니다.

r7은 실제 훈련 전후 능력치와 증가량, 점수가 움직인 장면, 주목 선수의 경기 활동과 다음 육성 선택을 결산에 연결합니다. 미세 성장·상한·휴식·기록 없는 기존 저장을 구분하며 훈련 성장과 경기 숙련 증가를 따로 보여줍니다.

저장은 사용한 기기·브라우저에 보관됩니다. 기존 저장을 지우거나 새 게임으로 덮어쓸 필요 없이 이어서 불러올 수 있습니다. 이전 기록이 없는 부분을 임의로 만들지 않습니다. 로컬 다운로드판과 공개 웹의 저장 공간은 다릅니다.

## 검증 범위

- r7-candidate1 동결본의 독립 QA에서 해당 변경 범위를 수용했습니다.
- 독립 네이티브 916항목과 브라우저 추가 18항목 통과. 기존 r6 저장 변환 결과 157개가 바이트 단위로 일치했습니다.
- 실제 브라우저 조작과 화면·기록 검토 11분 55.932초. 경기 중 새로고침과 브라우저 재시작 후 저장 지속성도 확인했습니다.
- 위 수치는 배포 전 동결본의 검사입니다. 공개 서버의 실행·응답 검증과 구분합니다.

## 남은 제한

- 웹 재저장 시 능력치 8개에서 최대 7.105427357601002e-15의 수치 차이가 발생하는 기존 엄격 동일성 실패는 남아 있습니다. r6에서도 같은 차이가 재현됩니다.
- 모바일·터치 실기기는 미검증이며, 기능 QA 통과는 사용 편의성이나 장기 재미의 입증이 아닙니다.
- 이번 게시 작업에서 월간 균형·능력별 대량 민감도 검사를 반복하지 않았습니다. 실제 경기 그래픽·애니메이션 개선은 후순위입니다.
